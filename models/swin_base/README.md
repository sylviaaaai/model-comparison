# Swin-Base

This folder contains the Swin-Base experiment artifacts used in the four-model mammography ROI comparison. The final model is a PyTorch/timm Swin Transformer classifier trained on the fixed patient-level 80/10/10 split.

## Final Model

- Backbone: `swin_base_patch4_window7_224.ms_in22k_ft_in1k`
- Framework: PyTorch/timm
- Input size: `224 x 224`
- Task: binary classification, `Benign` vs `Cancer`
- Positive class: `Cancer`
- Fine-tuning setting: `stage2_4`
- Unfrozen stages: `layers.1`, `layers.2`, and `layers.3`
- Dropout: `0.4`
- Batch size: `16`
- Final split: `results/splits/final_80_10_10`

## Grad-CAM Visualization

The Grad-CAM visualizations are generated by:

```text
models/swin_base/tools/gradcam_swin_torch.py
```

The final Grad-CAM outputs are stored in:

```text
models/swin_base/final_results/gradcam/
```

For each final test image, the script:

1. Loads the ROI image and resizes it to `224 x 224`.
2. Applies ImageNet mean/std normalization.
3. Runs the final Swin-Base model.
4. Applies `sigmoid` to the model logit to get `P(Cancer)`.
5. Uses threshold `0.5` for the predicted class.
6. Computes Grad-CAM for the selected target layer.
7. Groups the image by prediction outcome.

The saved groups are:

| Folder | Meaning |
| --- | --- |
| `correct_cancer` | True Cancer, predicted Cancer |
| `correct_benign` | True Benign, predicted Benign |
| `false_positive` | True Benign, predicted Cancer |
| `false_negative` | True Cancer, predicted Benign |

The final Grad-CAM folder stores 5 panels per group. Each panel contains the original image, the Grad-CAM heatmap, and an overlay.

## How The Grad-CAM Values Are Taken

The default target layer is:

```text
layers.3.blocks.1
```

This is a late block in the final Swin stage. The script registers:

- a forward hook to save the target-layer activations
- a backward hook to save gradients of the Cancer score with respect to those activations

For one image, the target score is the raw model logit for the positive class:

```text
score = logits[0]
```

Swin activations are not always emitted in standard CNN `B x C x H x W` format. The script converts activations and gradients into BCHW before computing CAM:

- If the tensor is `B x H x W x C` from timm Swin stages, it is permuted to `B x C x H x W`.
- If the tensor is token-shaped `B x tokens x C`, tokens are reshaped into a square spatial map and then converted to `B x C x H x W`.

After that conversion, the Grad-CAM calculation is:

1. Backpropagate from `score`.
2. Average gradients over height and width to get one weight per channel:

```text
weights = mean(gradients, dim=(height, width))
```

3. Multiply each activation channel by its gradient weight.
4. Sum across channels.
5. Apply ReLU to keep positive evidence for Cancer.
6. Upsample the CAM to `224 x 224`.
7. Min-max normalize the heatmap to `[0, 1]`.
8. Render with the `jet` colormap and overlay on the original image with alpha `0.40`.

In short, brighter Grad-CAM regions are spatial regions whose Swin features most positively increased the Cancer logit.

## Reproduction Command

```bash
python models/swin_base/tools/gradcam_swin_torch.py \
  --model-path models/swin_base/final_results/final/stage2_4/final_model.pt \
  --output-dir models/swin_base/final_results/gradcam \
  --target-layer layers.3.blocks.1
```

Grad-CAM maps are interpretation aids, not lesion segmentation masks.

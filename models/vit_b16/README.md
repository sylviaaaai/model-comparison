# ViT-B/16

This folder contains the ViT-B/16 experiment artifacts used in the four-model mammography ROI comparison. The final model is a PyTorch/timm `vit_base_patch16_224` classifier trained on the fixed patient-level 80/10/10 split.

## Final Model

- Backbone: `vit_base_patch16_224`
- Framework: PyTorch/timm
- Input size: `224 x 224`
- Patch size: `16 x 16`
- Patch grid: `14 x 14`, giving 196 image patch tokens
- Task: binary classification, `Benign` vs `Cancer`
- Positive class: `Cancer`
- Fine-tuning setting: `all_blocks`
- Dropout: `0.4`
- Batch size: `16`
- Final split: `results/splits/final_80_10_10`

The selected model unfreezes all 12 ViT Transformer blocks:

```text
blocks.0; blocks.1; ...; blocks.11
```

## Attention Visualization

The attention visualizations are generated by:

```text
models/vit_b16/tools/attention_rollout_vit_b16_torch.py
```

For each final test image, the script:

1. Loads the ROI image and resizes it to `224 x 224`.
2. Applies ImageNet mean/std normalization.
3. Runs the final ViT-B/16 model.
4. Applies `sigmoid` to the model logit to get `P(Cancer)`.
5. Uses threshold `0.5` for the predicted class.
6. Groups the image by prediction outcome.
7. Saves at most 5 panels per group.

The saved groups are:

| Folder | Meaning |
| --- | --- |
| `correct_cancer` | True Cancer, predicted Cancer |
| `correct_benign` | True Benign, predicted Benign |
| `false_positive` | True Benign, predicted Cancer |
| `false_negative` | True Cancer, predicted Benign |

Each panel contains the original image, the attention heatmap, and an overlay.

## How The Attention Values Are Taken

The script registers hooks on every ViT block attention module and recomputes attention from Q and K:

```text
attention = softmax((Q @ K^T) * scale)
```

The captured attention has shape approximately:

```text
batch x heads x tokens x tokens
```

For ViT-B/16 at `224 x 224`, the token count is 197: one CLS token plus 196 patch tokens.

### `attention_rollout/`

This is all-layer Attention Rollout.

For each Transformer block:

1. Average attention over heads.
2. Add the identity matrix to approximate the residual connection.
3. Normalize each row.
4. Multiply attention matrices across layers.

The final heatmap is the rollout from CLS token to patch tokens:

```text
mask = rollout[CLS, patch_tokens]
```

The `14 x 14` patch mask is upsampled to `224 x 224`.

### `attention_last_layer_cls_magma/`

This uses only the final Transformer block:

```text
mask = mean_over_heads(last_layer_attention)[CLS, patch_tokens]
```

It shows where the final CLS token directly attends immediately before classification. The folder uses the `magma` colormap.

### `attention_rollout_magma_discard09/`

This is Attention Rollout with weak patch-to-patch attention discarded.

Before rollout multiplication, the weakest 90% of the patch-to-patch attention values are set to zero:

```text
discard_ratio = 0.9
attention[:, 1:, 1:]
```

This produces sharper maps by emphasizing stronger attention paths and suppressing diffuse background attention.

## Reproduction Commands

Standard rollout:

```bash
python models/vit_b16/tools/attention_rollout_vit_b16_torch.py \
  --method rollout \
  --discard-ratio 0.0 \
  --output-dir models/vit_b16/final_results/attention_rollout
```

Last-layer CLS attention:

```bash
python models/vit_b16/tools/attention_rollout_vit_b16_torch.py \
  --method last_layer_cls \
  --cmap magma \
  --output-dir models/vit_b16/final_results/attention_last_layer_cls_magma
```

Rollout with 90% weak-attention discard:

```bash
python models/vit_b16/tools/attention_rollout_vit_b16_torch.py \
  --method rollout \
  --discard-ratio 0.9 \
  --cmap magma \
  --output-dir models/vit_b16/final_results/attention_rollout_magma_discard09
```

These maps are interpretation aids, not lesion segmentation masks.

For the lesion-mask overlap experiment, the primary ViT saliency method is the
standard `attention_rollout/` output with `discard_ratio = 0.0`. The
`attention_rollout_magma_discard09/` folder is retained as an auxiliary sharper
visualization, not as the current overlap-analysis path.

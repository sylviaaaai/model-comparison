# ResNet50

This folder contains the ResNet50 experiment artifacts used in the four-model mammography ROI comparison. The final model is a Keras ResNet50 classifier trained on the fixed patient-level 80/10/10 split.

## Final Model

- Backbone: Keras `ResNet50`
- Pretraining: ImageNet-1K
- Input size: `224 x 224`
- Task: binary classification, `Benign` vs `Cancer`
- Positive class: `Cancer`
- Fine-tuning setting: `conv3_5`
- Batch size: `16`
- Dropout: `0.4`
- ResNet preprocessing: enabled
- Final split: `results/splits/final_80_10_10`

The selected fine-tuning setting, `conv3_5`, unfreezes ResNet50 convolutional stages from conv3 through conv5 while keeping BatchNorm behavior controlled by the training script.

## Grad-CAM Visualization

The Grad-CAM visualizations are generated by:

```text
models/resnet50/tools/gradcam_resnet50.py
```

The final Grad-CAM outputs are stored in:

```text
models/resnet50/final_results/gradcam/
```

For each final test image, the script:

1. Loads the ROI image and resizes it to `224 x 224`.
2. Runs the final ResNet50 model.
3. Uses the model output for the Cancer class as the target score.
4. Computes Grad-CAM for the selected convolutional feature layer.
5. Uses threshold `0.5` for the predicted class.
6. Groups the image by prediction outcome.
7. Saves at most 5 panels per group.

The saved groups are:

| Folder | Meaning |
| --- | --- |
| `correct_cancer` | True Cancer, predicted Cancer |
| `correct_benign` | True Benign, predicted Benign |
| `false_positive` | True Benign, predicted Cancer |
| `false_negative` | True Cancer, predicted Benign |

Each panel contains the original image, the Grad-CAM heatmap, and an overlay.

## How The Grad-CAM Values Are Taken

The script first locates the nested Keras ResNet50 backbone named `resnet50`. If no layer is manually provided with `--last-conv-layer`, it scans the backbone from the end and selects the last layer with a 4D output tensor. In standard Keras ResNet50 this corresponds to the final spatial feature map near `conv5_block3_out`.

It then builds a Grad-CAM model that returns:

```text
selected convolution feature map
final model prediction
```

For one image, the target score is:

```text
cancer_score = prediction[:, 0]
```

The heatmap is computed as:

1. Take the gradient of `cancer_score` with respect to the selected convolution feature map.
2. Average the gradients over spatial dimensions to get one weight per channel:

```text
pooled_grads = mean(grads, axis=(height, width))
```

3. Multiply each feature-map channel by its pooled gradient weight.
4. Sum across channels.
5. Apply ReLU so only positive evidence for the Cancer class remains.
6. Normalize by the maximum heatmap value.
7. Resize the heatmap back to `224 x 224`.
8. Render it with the `jet` colormap and overlay it on the original image with alpha `0.40`.

In short, brighter Grad-CAM regions indicate spatial locations whose convolutional features most positively contributed to the Cancer score.

## Reproduction Command

```bash
python models/resnet50/tools/gradcam_resnet50.py \
  --model-path models/resnet50/final_results/final/conv3_5/final_model.keras \
  --output-dir models/resnet50/final_results/gradcam
```

To force a specific convolutional layer:

```bash
python models/resnet50/tools/gradcam_resnet50.py \
  --last-conv-layer conv5_block3_out
```

Grad-CAM maps are interpretation aids, not lesion segmentation masks.

# Paper-Ready Planning Files

This folder contains the two highest-level paper planning files copied from
the Grad-CAM mask-overlap analysis package.

## Files

```text
00_results_index.md
  Paper-facing index of current source-of-truth files, denominators, tables,
  figures, limitations, and manuscript-use guidance.

01_experiment_closeout.md
  Closeout summary of completed analysis lines, main conclusions, remaining
  manuscript decisions, and GitHub packaging status.
```

## Recommended Use

Read `00_results_index.md` first when writing Methods, Results, Tables,
Figures, or Supplementary Materials.

Read `01_experiment_closeout.md` when deciding whether the analysis is ready
to move from experiments into manuscript drafting.

# Qualitative Saliency Examples Across Mask Types and Artifacts

This folder contains supervisor-facing qualitative saliency-mask panels. The final curated panel set is stored in:

```text
panels_by_case_type_final/
```

Start with `panels_by_case_type_final/README.md`, then use `panels_by_case_type_final/panel_index.csv` as the source of truth for the selected cases and panel paths.

These examples are for qualitative review only. They illustrate mask types, marker-positive cases, excluded masks, model-disagreement cases, and ResNet50 zero-saliency examples; they do not replace the quantitative overlap tables.
